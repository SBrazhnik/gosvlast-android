# Власть РФ — Android

Интерактивная схема государственного устройства России: органы власти, должностные лица, все 450 депутатов Госдумы IX созыва, доходы, расследования.

## Сборка APK через GitHub
1. Создайте репозиторий и загрузите в него содержимое этой папки (ветка `main`).
2. Откройте вкладку **Actions** → **Build APK**. Сборка запускается при каждом push или вручную (Run workflow).
3. Готовый файл — в артефакте **GosVlast-apk** на странице запуска. Для тега `v1.0` и т.п. APK также прикрепляется к GitHub Release.

APK подписан отладочным ключом: его можно установить на телефон (разрешите установку из неизвестных источников), но для Google Play нужна подпись своим ключом.

## Обновление данных
Данные встроены в приложение. Кнопка «Актуализировать данные» загружает `data.json` из корня этого репозитория (ветка `main`), адрес подставляется при сборке. Достаточно обновить `data.json` и сделать commit — пересобирать APK не нужно.

Формат `data.json`: `{ "people": [...], "meta": {"updated": "YYYY-MM-DD", "alert": "..."}, "roster": {"list": [...]} }`.

## Структура
- `app/src/main/assets/index.html` — сама схема (HTML/JS, работает офлайн).
- `app/src/main/java/ru/gosvlast/app/MainActivity.kt` — WebView-обёртка; внешние ссылки открываются в браузере.
- `.github/workflows/build-apk.yml` — сборка.
